# awesome-jank
A list of awesome jank projects.

## Libraries
### Graphics and windowing
* ![jank commons](https://img.shields.io/badge/jank_commons-orange) [glfw-sys](https://github.com/jank-lang/commons/tree/main/glfw-sys) - Raw package for GLFW
* ![jank commons](https://img.shields.io/badge/jank_commons-orange) [imgui-sys](https://github.com/jank-lang/commons/tree/main/imgui-sys) - Raw package for Dear ImGUI
* ![jank commons](https://img.shields.io/badge/jank_commons-orange) [imgui-glfw-sys](https://github.com/jank-lang/commons/tree/main/imgui-glfw-sys) - Raw package for Dear ImGUI GLFW platform backend
* ![jank commons](https://img.shields.io/badge/jank_commons-orange) [imgui-opengl2-sys](https://github.com/jank-lang/commons/tree/main/imgui-opengl2-sys) - Raw package for Dear ImGUI OpenGL2 renderer backend
* ![jank commons](https://img.shields.io/badge/jank_commons-orange) [raylib-sys](https://github.com/jank-lang/commons/tree/main/raylib-sys) - Raw package for raylib
* ![jank commons](https://img.shields.io/badge/jank_commons-orange) [gl-sys](https://github.com/jank-lang/commons/tree/main/gl-sys) - Raw package for OpenGL
