# awesome-jank
A curated list of awesome jank projects. Anything with a ![jank commons](https://img.shields.io/badge/commons-green) badge is an official package in the [jank commons](https://github.com/jank-lang/commons) repository.

## Libraries
### Graphics and windowing
* [glfw-sys](https://github.com/jank-lang/commons/tree/main/glfw-sys) ![jank commons](https://img.shields.io/badge/commons-green) - Raw package for GLFW
* [imgui-sys](https://github.com/jank-lang/commons/tree/main/imgui-sys) ![jank commons](https://img.shields.io/badge/commons-green) - Raw package for Dear ImGUI
* [imgui-glfw-sys](https://github.com/jank-lang/commons/tree/main/imgui-glfw-sys) ![jank commons](https://img.shields.io/badge/commons-green) - Raw package for Dear ImGUI GLFW platform backend
* [imgui-opengl2-sys](https://github.com/jank-lang/commons/tree/main/imgui-opengl2-sys) ![jank commons](https://img.shields.io/badge/commons-green) - Raw package for Dear ImGUI OpenGL2 renderer backend
* [raylib-sys](https://github.com/jank-lang/commons/tree/main/raylib-sys) ![jank commons](https://img.shields.io/badge/commons-green) - Raw package for raylib
* [gl-sys](https://github.com/jank-lang/commons/tree/main/gl-sys) ![jank commons](https://img.shields.io/badge/commons-green) - Raw package for OpenGL

### Physics engines
* [box2d-sys](https://github.com/jank-lang/commons/tree/main/box2d-sys) ![jank commons](https://img.shields.io/badge/commons-green) - Raw package for box2d
* [box3d-sys](https://github.com/jank-lang/commons/tree/main/box3d-sys) ![jank commons](https://img.shields.io/badge/commons-green) - Raw package for box3d

### Databases
* [sqlite3-sys](https://github.com/jank-lang/commons/tree/main/sqlite3-sys) ![jank commons](https://img.shields.io/badge/commons-green) - Raw package for sqlite3

### Graphical UIs (GUIs)
* [raygui-sys](https://github.com/jank-lang/commons/tree/main/raygui-sys) ![jank commons](https://img.shields.io/badge/commons-green) - Raw package for raygui
* [jank-slint](https://github.com/kylc/jank-slint) - Bindings to the Slint GUI toolkit for jank

### Terminal UIs (TUIs)
* [ftxui-sys](https://github.com/jank-lang/commons/tree/main/ftxui-sys) ![jank commons](https://img.shields.io/badge/commons-green) - Raw package for FTXUI

## Development tooling
### jank-build helpers
* [jank-build-cmake](https://github.com/jank-lang/commons/tree/main/jank-build-cmake) ![jank commons](https://img.shields.io/badge/commons-green) - Build script helper for building CMake packages
* [jank-build-pkg-config](https://github.com/jank-lang/commons/tree/main/jank-build-pkg-config) ![jank commons](https://img.shields.io/badge/commons-green) - Build script helper for querying libraries via pkg-config
