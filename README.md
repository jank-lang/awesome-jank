# awesome-jank
A list of awesome jank projects.

## Libraries
### Graphics and windowing
* [org.jank-lang.commons/glfw-sys](https://github.com/jank-lang/commons/tree/main/glfw-sys) - Raw package for GLFW
* [org.jank-lang.commons/imgui-sys](https://github.com/jank-lang/commons/tree/main/imgui-sys) - Raw package for Dear ImGUI
* [org.jank-lang.commons/imgui-glfw-sys](https://github.com/jank-lang/commons/tree/main/imgui-glfw-sys) - Raw package for Dear ImGUI GLFW platform backend
* [org.jank-lang.commons/imgui-opengl2-sys](https://github.com/jank-lang/commons/tree/main/imgui-opengl2-sys) - Raw package for Dear ImGUI OpenGL2 renderer backend
* [org.jank-lang.commons/raylib-sys](https://github.com/jank-lang/commons/tree/main/raylib-sys) - Raw package for raylib
* [org.jank-lang.commons/gl-sys](https://github.com/jank-lang/commons/tree/main/gl-sys) - Raw package for OpenGL

### Physics engines
* [org.jank-lang.commons/box2d-sys](https://github.com/jank-lang/commons/tree/main/box2d-sys) - Raw package for box2d
* [org.jank-lang.commons/box3d-sys](https://github.com/jank-lang/commons/tree/main/box3d-sys) - Raw package for box3d

### Databases
* [org.jank-lang.commons/sqlite3-sys](https://github.com/jank-lang/commons/tree/main/sqlite3-sys) - Raw package for sqlite3

### Terminal UIs
* [org.jank-lang.commons/ftxui-sys](https://github.com/jank-lang/commons/tree/main/ftxui-sys) - Raw package for FTXUI

## Development tooling
### jank-build helpers
* [org.jank-lang.commons/jank-build-cmake](https://github.com/jank-lang/commons/tree/main/jank-build-cmake) - Build script helper for building CMake packages
* [org.jank-lang.commons/jank-build-pkg-config](https://github.com/jank-lang/commons/tree/main/jank-build-pkg-config) - Build script helper for querying libraries via pkg-config
